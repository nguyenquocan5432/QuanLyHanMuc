# Tài liệu của đồ án

Thư mục này chứa hình ảnh, sơ đồ và bảng biểu dùng trong báo cáo cuối kỳ.

| Thư mục | Nội dung |
|---|---|
| `bao-cao/` | Báo cáo cuối kỳ (.docx) và slide thuyết trình (.pptx) |
| `so-do/` | Các sơ đồ trong báo cáo, mỗi sơ đồ có bản `.svg` (gốc) và `.png` |
| `giao-dien/` | Ảnh các màn hình của ứng dụng |
| `chay-thu/` | Ảnh chụp khi chạy thật trên máy: Docker Desktop, trang chủ, trang không có quyền, kết quả `dotnet test` |
| `bang-bieu/` | 78 bảng của báo cáo, chép sang Markdown theo từng chương, giữ đúng số thứ tự trong báo cáo |

## Tên file trong `so-do/`

| Tiền tố | Loại sơ đồ |
|---|---|
| `uc_tongquat`, `uc01` đến `uc13` | Biểu đồ use case tổng quát và từng use case |
| `hd_` | Biểu đồ hoạt động |
| `sq01` đến `sq13` | Biểu đồ tuần tự |
| `st_` | Biểu đồ trạng thái |
| `lop_phantich`, `lop_chitiet` | Biểu đồ lớp phân tích và lớp chi tiết |
| `tk01` đến `tk13` | Biểu đồ lớp thiết kế (boundary, control, entity) của từng use case |
| `logic` | Sơ đồ quan hệ giữa các bảng (ERD) |
| `kientruc` | Kiến trúc hệ thống |
| `trienkhai` | Sơ đồ triển khai bằng Docker |
| `dieuhuong` | Sơ đồ điều hướng giữa các màn hình |
